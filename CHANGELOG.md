# Changelog

## 0.2.0
- Replaced the limited single-call starter UI with the Medut Softphone Windows/Android call-management architecture.
- Added multi-account calling, Add Call, call waiting, hold/swap, attended transfer, messaging, presence, richer diagnostics, native Android calling and Windows tray support through the pinned upstream source.
- Removed the incorrectly implemented PBX conference-room shortcut from the active application.
- Local three-way audio mixing remains a separate native SDK task and is not represented as available.
